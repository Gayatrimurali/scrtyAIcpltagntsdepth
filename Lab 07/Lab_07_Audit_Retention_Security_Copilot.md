# Lab 07: Purview Audit, Retention, and Security Copilot

### Estimated time: 30 Minutes

## Introduction

The final lab in the Zava Corporation AI security course brings together audit investigation, data lifecycle management, and AI-assisted security analysis. Microsoft Purview captures every Copilot and agent interaction as a structured audit record - including the prompt context, files referenced, and sensitivity labels applied. These records can be retained for compliance obligations, searched for forensic investigations, and analysed using Security Copilot's embedded intelligence.

In this lab, Patti Fernandes generates targeted agent interaction signals to populate the audit log and investigates those interactions using Purview Audit, searching for CopilotInteraction and Copilot Studio agent management events. you will creates a retention policy that governs the lifecycle of all Copilot and agent interaction data. Patti then uses Security Copilot - both embedded in Purview and in the standalone portal - to summarise DLP alerts and query the organisation's AI security posture.

## Scenario

Zava's legal team has requested that all AI agent interaction data be retained for a minimum of five years to satisfy financial services regulatory obligations. In parallel, the CISO has asked the SOC team to demonstrate that Purview Audit is capturing meaningful forensic data from the Zava agent estate, and that Security Copilot can accelerate triage of AI-related security events.

Patti Fernandes will investigate audit records with the Zava HR Assistant, review agent management events logged from agent creation and publishing, and confirm that DLP match events are recorded. ODL User will create and verify the retention policy. Patti will complete the course by using Security Copilot to summarise the Day 2 and Day 3 security findings across the Zava environment.

## Objectives

- Generate agent interaction audit signals as Patti Fernandes via the Zava HR Assistant.
- Search Purview Audit for `CopilotInteraction` events and review interaction record fields.
- Search for Copilot Studio agent management events - publish, configure, and update activities.
- Review DLP match audit records generated by the Lab 04 and Lab 06 policies.
- Create a retention policy for Copilot and AI app interactions scoped to all users.
- Verify the retention policy configuration and confirm the policy location covers Copilot Studio.
- Use Security Copilot in Purview to summarise DLP alerts and query AI posture.
- Use Security Copilot standalone to run a custom prompt scoped to Zava agent findings.

### Task 2: Create the Retention Policy as ODL User

1. Open a new browser tab and sign in as **ODL User** at `https://purview.microsoft.com`. In the left navigation pane, Select **Data Lifecycle Management** from **Solutions**.

    ```
    https://purview.microsoft.com
    ```

	![](./media/l07-e4-t2-s1.png)

2. In the left sub-navigation, select **Retention policies** from **Policies** and click **+ New retention policy**.

	![](./media/l07-e4-t2-s2.png)

3. On the **Name your retention policy** page, enter the following:

   - **Name:** `Zava - Retain AI Interactions 5 Year`
   - **Description:** `Retains all Microsoft 365 Copilot and Copilot Studio agent interaction data - including prompts and responses - for a minimum of five years to satisfy Zava financial services regulatory obligations.`

4. Select **Next** until you are asked to select the **type**.

	![](./media/l07-e4-t2-s4.png)

5. On the **Choose the type of retention policy to create** page, select **Static** and click **Next**.

	![](./media/l07-e4-t2-s5.png)

6. On the **Choose where to apply this policy** page, deselect all locations that are toggled **On** by default. Toggle **Microsoft Copilot experiences** to **On**.

7. Confirm the scope shows **All users** under the included entries.

   > **Note:** The **Microsoft Copilot experiences** retention location covers user prompts and responses for both Microsoft 365 Copilot and Copilot Studio agents. Interaction data is stored in a hidden Exchange mailbox folder for each user - not directly accessible to users or administrators, but searchable via eDiscovery and subject to the retention policy configured here.

8. Select **Next**.

	![](./media/l07-e4-t2-s8.png)

9. On the **Decide if you want to retain content, delete it, or both** page, configure the following:

   - **Retain items for a specific period:** Select **5 years**.
   - **Start the retention period based on:** Select **When items were created**.
   - **At the end of the retention period:** Select **Do nothing**.

10. Click **Next**.

	![](./media/l07-e4-t2-s10.png)

11. On the **Review and finish** page, review the full policy configuration and select **Submit**.

	![](./media/l07-e4-t2-s13.png)

14. On the confirmation page, select **Done**.

	![](./media/l07-e4-t2-s14.png)



### Task 3: Verify the Retention Policy

1. On the **Retention policies** page, locate **Zava - Retain AI Interactions 5 Year**.

3. Select the policy to open its detail panel.

	![](./media/n1.png)

4. On the detail panel, confirm that:

   - **Status** is **Enabled**.
   - **Locations** shows **Microsoft Copilot experiences**.
   - **Retention period** shows **5 years**.

	   ![](./media/l07-e4-t3-s4.png)

5. Close the detail panel.

   > **Note:** It can take up to seven days for a new retention policy to be distributed to all selected locations and applied to existing content. The policy will apply to all new and existing Copilot and agent interaction data stored in the hidden Exchange mailbox folder for each Zava user. If a user leaves the organisation, their interaction data remains subject to this policy for the duration of the retention period.
